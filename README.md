# 🌾 Agricultural Research Centre Website

A responsive Agricultural Research Centre website developed using **HTML, CSS, and JavaScript**. This project provides information about various crops, livestock, farming techniques, and sustainable agricultural practices through an easy-to-use web interface.

---

## 📌 About

The Agricultural Research Centre Website is an educational platform designed to provide farmers, students, and researchers with useful information about modern agriculture. It includes details about crops, animal husbandry, nurseries, mushrooms, and sustainable farming practices.

---

## ✨ Features

- 🏠 Responsive Home Page
- 🌱 Crop Information
- 🌾 Modern Farming Techniques
- 🐄 Livestock Information
- 🍄 Mushroom Cultivation
- 🌿 Nursery Management
- 📱 Mobile-Friendly Design
- 🎨 Clean and Interactive User Interface

---

- HTML5
- CSS3
- JavaScript
